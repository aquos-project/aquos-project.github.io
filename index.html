AQUOS — La douche qui recycle l’eau intelligemment AQUOS — The intelligently recycling shower

Aquos is un système innovant qui permet de réutiliser l’eau de la douche en temps réel, tout en garantissant une eau propre, filtrée et désinfectée. Aquos is an innovative system that allows you to reuse shower water in real-time, while guaranteeing clean, filtered, and disinfected water.

Objectif : Réduire la consommation d’eau jusqu’à 70 % Goal: Reduce water consumption by up to 70 %

Comment ça marche ? How does it work?

1. L’eau est récupérée1. Water is collected

L’eau qui s’écoule dans la douche est collectée dans un petit réservoir.

2. Elle est filtrée2. It is filtered

Elle passe dans plusieurs filtres qui retirent les cheveux, les impuretés et les particules fines.

3. Elle est désinfectée3. It is disinfected

Une puissante lumière UV-C élimine les bactéries et les micro-organismes.

4. Elle est renvoyée propre4. It is sent back clean

Une pompe renvoie l’eau filtrée vers la pomme de douche pour être réutilisée immédiatement.

5. Tout est automatique5. Everything is automatic

Une carte électronique surveille l'eau en permanence. L’utilisateur ne fait… rien.

Comment l'eau est-elle purifiée ?

1

Filtre Mécanique

Une grille fine qui retient immédiatement les cheveux, grosses particules et résidus de savon.

2

Charbon Actif

Une cartouche haute performance qui élimine les mauvaises odeurs et les micro-polluants.

3

Lampe UV-C

Stérilisation instantanée : la lumière ultraviolette détruit 99,9 % des bactéries et virus.

La Technologie

🧠 Un cœur intelligent

L’Arduino Uno R3 est la carte principale qui lit les capteurs et pilote les actionneurs matériels en temps réel, tandis que l’Arduino Nano 33 IoT gère de manière autonome la liaison Wi-Fi et l'envoi des données.

👁️ Les Capteurs

  • Niveau : Vérifie l'eau disponible.
  • Turbidité : Mesure si l'eau est claire.
  • TDS : Mesure la pureté chimique (savon).
  • Température : Assure votre confort.

⚙️ Les Actionneurs

  • Pompe : Renvoie l’eau filtrée.
  • Électrovannes : Dirigent l'eau.
  • Lampe UV-C : Désinfecte l’eau.
  • Résistance : Maintient la chaleur.

Architecture Réseau & Parcours de la Donnée

Découvrez comment les mesures physiques de la cabine AQUOS traversent le réseau en temps réel pour alimenter cette interface web.

1. Collecte Locale

L'Arduino Uno R3 interroge les capteurs (DS18B20, TDS, Turbidité) via les bus de communication (OneWire, Analogique) et pilote toute la logique matérielle.

2. Émission Wi-Fi

L'Arduino Nano 33 IoT récupère les données de l'Uno par liaison série (UART) et les envoie sans fil via des requêtes MQTT.

3. Serveur Cloud

Le serveur Adafruit IO reçoit le flux, l'historise et le met à disposition instantanément via son API REST publique.

4. Interface Web

Notre script JavaScript exécute un Fetch asynchrone toutes les 3s, découpe la chaîne et anime nos jauges CSS.

Questions Fréquentes

Oui. L'eau subit une filtration mécanique pour les grosses particules, passe par du charbon actif pour les odeurs et micro-polluants, et est instantanément stérilisée par une lampe UV-C détruisant 99.9% des bactéries.

Les capteurs de turbidité et de TDS surveillent la qualité de l'eau en temps réel. Si la qualité baisse en dessous des seuils sanitaires de sécurité, le système AQUOS coupe automatiquement le recyclage et rejette l'eau vers les égouts.

L'entretien est minime. Il suffit de vider la petite grille de pré-filtre une fois par semaine (comme une douche classique) et de remplacer la cartouche de charbon actif tous les 6 mois.
